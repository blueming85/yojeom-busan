# 상세 요약

## 📋 주요 내용
부산시(시장 박형준)는 2025년 9월 11일부터 12일까지 전북특별자치도 군산새만금컨벤션센터에서 열린 제42회 지역정보화 우수사례 발표대회에서 행정안전부장관상을 수상하였다. 이번 대회는 전국 16개 시도에서 연구과제를 제출하였으며, 국민 심사와 서면심사, 현장평가를 통해 수상 기관이 선정되었다. 부산시는 지자체 최초로 구축한 데이터 시장(마켓) 서비스와 데이터 통합저장소, 데이터 통합지도 등 다양한 정책 활용 사례를 포함한 부산형 데이터 통합 플랫폼(Big-데이터웨이브)의 구축 성과를 발표하였다. 데이터 시장 서비스는 지역 데이터 기업 간 협력과 공동 활용, 분석을 통한 시너지 창출, 정보 교류 및 홍보의 장으로 발전시켰으며, 데이터 플랫폼은 공공과 민간 데이터를 개방·활용하는 체계를 마련하여 누구나 데이터를 분석하고 활용할 수 있도록 지원한다. 이 성과는 공공과 민간의 협업을 통해 데이터 생태계를 조성하고 지역 데이터 산업 활성화에 기여한 점이 높이 평가받았다. 부산시는 이번 수상을 계기로 데이터 기반 행정 혁신을 가속화하며, 인공 지능 등 디지털 기술을 활용한 시민 중심 맞춤형 행정을 지속적으로 추진할 계획이다. 조영태 부산시 행정자치국장은 이번 성과를 인정받아 앞으로도 디지털 기술을 활용한 행정서비스 발굴과 지속 가능한 디지털 혁신에 최선을 다하겠다고 밝혔다.

## 🎯 핵심 포인트
- 부산시는 2025년 9월 11~12일 전북 군산에서 열린 제42회 지역정보화 우수사례 발표대회에서 행정안전부장관상을 수상하였다.
- 대회는 전국 16개 시도에서 연구과제를 제출하였으며, 국민 심사와 현장평가를 통해 수상 기관이 선정되었다.
- 부산시는 지자체 최초로 구축한 데이터 시장(마켓) 서비스와 데이터 통합플랫폼(Big-데이터웨이브)의 성과를 발표하였다.
- 데이터 시장은 지역 데이터 기업 간 협력과 공동 활용, 정보 교류를 촉진하는 역할을 하며, 데이터 플랫폼은 공공·민간 데이터를 개방·활용하는 기반을 제공한다.
- 이번 성과는 공공과 민간의 협업으로 데이터 생태계 조성과 지역 데이터 산업 활성화에 기여하였다.
- 부산시는 이번 수상을 계기로 데이터 기반 행정 혁신을 더욱 강화하고, 시민 맞춤형 디지털 서비스를 지속적으로 발굴할 예정이다.
